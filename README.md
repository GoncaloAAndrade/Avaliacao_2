# Projeto 2ªAvaliação

Este projeto consiste numa página web sobre o GitHub.

## Descrição

Utilização do GitHub para avaliação.
O projeto foi desenvolvido no ambito da formação de desenvolvimento web.

## Terminologias utilizadas

- HTML
- CSS

## Estrutura do projeto

- Index que contém estrutura e conteúdo da página.
- CSS para estilos visuais da página.

## Funcionalidades

- Informação sobre o GitHub.
- Botão para o site oficial do GitHub.

## Como executar
1. Descarregue o projeto
2. Abra o ficheiro index.html
3. Carregue no botão para visitar a página do GitHub
